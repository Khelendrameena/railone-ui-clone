# RailOne – UI Clone

A front-end UI clone of the RailOne app screens (home, bookings, ticket
details, profile), built as a single-page HTML app and split into:

- `index.html` — markup (screens, embedded assets)
- `index.css` — all styles
- `index.js` — navigation / rendering logic

Open `index.html` in a browser to run it. UI/UX learning project only;
not affiliated with IRCTC or Indian Railways.
